# BOBOY — сенсорное меню + админка

Сайт для сенсорного экрана в ресторане BOBOY:

- **Заставка** — логотип, парящие блюда и акварельные иллюстрации из печатного меню. Гость касается экрана, и открывается меню.
- **Меню** — категории карточками, внутри категории вкладки и список блюд (фото, название, описание, цена). По нажатию на блюдо открывается его страница.
- **4 языка** — O'zbek, Ўзбек, Русский, English. Выбранный язык остаётся для следующих гостей, пока кто-то не поменяет его снова.
- Если 60 секунд никто не трогает экран, открывается заставка.
- Экран может стоять **вертикально или горизонтально**, раскладка подстраивается сама.
- Изменения из админки появляются на экране в течение минуты, перезагружать ничего не нужно.
- Если пропал интернет, экран продолжает показывать сохранённое меню.

**Админка** находится по адресу `/admin`, вход по паролю, работает с телефона и компьютера. В ней можно:

- добавлять, переименовывать, скрывать, удалять и переставлять категории;
- добавлять и изменять блюда: фото (необязательно), название и описание отдельно на каждом языке, цену (или две цены «Сингл / Дабл»);
- ставить скидку в процентах или новой ценой;
- убирать блюдо в стоп-лист и менять порядок блюд.

## Запуск

Нужен **Node.js 22.13 или новее** (подойдут 22 LTS и 24). Никаких дополнительных программ ставить не нужно: база SQLite встроена в Node.js.

```bash
npm install
ADMIN_PASSWORD='придумайте-пароль' npm start
```

На Windows пароль задаётся так: `set ADMIN_PASSWORD=придумайте-пароль` и затем `npm start`.

Сайт откроется на `http://localhost:3000`, админка — на `http://localhost:3000/admin`.

Переменные окружения:

| Переменная | Что это | По умолчанию |
|---|---|---|
| `ADMIN_PASSWORD` | пароль админки | `boboy2026` (**обязательно поменять**) |
| `PORT` | порт | `3000` |
| `DATA_DIR` | папка с базой и фото | `./data` |

При первом запуске база `data/menu.db` сама заполняется стартовым меню из папки `seed/`: шашлыки и напитки, для которых есть фото.

### Docker

```bash
docker build -t boboy-menu .
docker run -d --name boboy-menu -p 3000:3000 \
  -e ADMIN_PASSWORD='придумайте-пароль' \
  -v boboy-data:/app/data --restart unless-stopped boboy-menu
```

### Важно для деплоя

- Нужен сервер, на котором запускается Node.js: VPS, Railway, Render, Fly.io и подобные. Статический хостинг (Netlify, GitHub Pages) **не подойдёт**: нужны база и загрузка фото.
- Папка `data/` (база SQLite и загруженные фото) должна **сохраняться между перезапусками**: постоянный диск или volume. Бэкап — это просто копия этой папки.
- Лучше открыть сайт по HTTPS (nginx или Caddy перед Node). Тогда включается офлайн-режим экрана.

## Настройка сенсорного экрана

1. Открыть адрес сайта во встроенном браузере экрана на весь экран.
   - **Android-экран:** Chrome → «Добавить на главный экран» (откроется без адресной строки) или приложение *Fully Kiosk Browser*.
   - **Windows / мини-ПК:** `chrome --kiosk --noerrdialogs https://ваш-адрес`
2. Отключить сон и выключение экрана в настройках устройства.
3. Язык по умолчанию — O'zbek. Дальше экран запоминает последний выбранный язык.

## Откуда взяты данные

- **Шашлыки:** названия и описания из печатного меню (PDF), цены из `БОБОЙ.xlsx`.
- **Напитки:** в PDF их нет, поэтому названия и цены взяты из `БОБОЙ.xlsx`, без описаний. Если в Excel у кофе две цены, показываются обе: «Сингл / Дабл».
- Переводы на узбекский (латиница и кириллица) и английский сделаны по русскому тексту. Их стоит показать носителю языка и поправить в админке.
- **Проверьте в админке**, правильно ли подобраны названия к фото. Эти напитки похожи внешне, и я сопоставлял их на глаз:
  - лимонады «клубника-личи» и «клубника с ананасом»;
  - айс ти: гибискус и фруктовый;
  - компоты: микс и курага;
  - Red Bull мохито;
  - милкшейки: классический и тоффи-карамель;
  - смузи: клубника-малина и ягодный;
  - фреши: яблочный, морковный, апельсиновый, яблоко-морковь, яблоко-апельсин-морковь;
  - латте и раф, айс латте, фраппучино.

  Из шашлыков так же проверьте «Баранина кусковой» и «Говядина кусковой».
- Большое ассорти шашлыков не добавлено как блюдо: в PDF такого нет. Его фото стоит обложкой категории «Шашлыки».

## Структура

```
server.js            сервер (Express + встроенный SQLite)
public/              экран меню (index.html, css, js) и админка (public/admin)
seed/menu.json       стартовое меню, seed/photos — фото блюд
seed/build_seed.py   как собиралось стартовое меню (для истории)
data/                создаётся при запуске: menu.db + uploads/
```
